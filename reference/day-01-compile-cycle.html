Compile cycle

A Rust program starts as readable source code. The compiler checks it and produces a binary you run on the target platform.

1 · writehello.rsRust source code
2 · compilerustc hello.rsChecks and produces a binary
3 · run./helloExecutes the compiled program
Default target: a binary built normally runs for the platform it was built for. Producing a binary for another platform is called cross-compilation.
