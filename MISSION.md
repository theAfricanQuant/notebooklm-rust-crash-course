# Mission: Rust Crash Course

## Why
Build practical Rust fluency by completing one small, hands-on chapter each day from the downloaded crash course. The immediate goal is to read, run, alter, and explain simple Rust programs rather than merely watch tutorials.

## Success looks like
- Independently create, compile, and run a small Rust program.
- Explain the purpose of the toolchain and the core language constructs encountered in each lesson.
- Turn each daily concept into a small working change before moving to the next chapter.

## Constraints
- One focused lesson per day, beginning with `03-introduction.md`.
- Lessons are short, interactive HTML built from the downloaded NotebookLM Markdown. External Rust material is explicitly optional supplementation.
- Build foundations before frameworks, async runtimes, or `unsafe` Rust.
- Use Zed and its integrated terminal for every hands-on lesson.

## Out of scope
- Web frameworks, embedded Rust, and advanced performance tuning until the core language is secure.
