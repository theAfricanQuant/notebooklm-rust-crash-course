# Teaching notes

- User preference: one chapter per day, in the order of the NotebookLM exports, beginning with `03-introduction.md`.
- Present material as polished, interactive HTML rather than prose-heavy notes.
- The downloaded Markdown is the source of truth. Rust Book, Rustlings, and other material may only appear as clearly labelled optional supplementation.
- Every lesson must include a self-contained Zed Lab: open the relevant folder in Zed, use its integrated terminal, and run the lesson command.
- Do not add a learning record or glossary term until the learner demonstrates understanding.
