Let Cargo run the project

Create a properly structured Rust project, then build, check, format, and run it with Cargo.

35–45 minutesOne tangible winCargo & rustfmt

Why today changes the workflow

Yesterday, rustc hello.rs compiled one loose file. That is useful for seeing the raw compile cycle. Real programs need a home for source files, dependency information, and build output. Cargo gives a Rust project that home and invokes the compiler for you.

Course source: Tech With Tim’s Rust Programming Tutorial.

The project you are about to create

InstructionsCargo.tomlThe package name, version, Rust edition, and future dependencies.
Your codesrc/main.rsThe program entry point: it contains fn main().
Build outputtarget/Created by Cargo. It holds compiled files and should stay out of Git.

Cargo.lock will also appear after the first build. Cargo maintains it to record exact dependency versions; leave it to Cargo.

Zed Lab · use this every day

Create and run your first Cargo project

  1. Open notebooklm-rust-crash-course in Zed.
  2. Press Ctrl + ` to open Zed’s integrated terminal.
  3. Run the commands below exactly. The --vcs none option keeps this practice project inside the course repository instead of making a nested Git repository.
cd practice
cargo new --vcs none cargo-greeting
cd cargo-greeting
cargo run

Success is the default Hello, world! message and a new cargo-greeting/ folder containing Cargo.toml and src/main.rs.

Do this now

Make the greeting yours

Open practice/cargo-greeting/src/main.rs in Zed. Replace its contents with this, save the file, and run the three commands from the project folder:

fn main() {
    println!("Hello from Siseng's Cargo project!");
}
cargo fmt
cargo check
cargo run

cargo fmt formats the Rust files in the project (it uses rustfmt). cargo check type-checks the code without producing the final executable. cargo run builds when needed and runs the result. Your terminal should print your new greeting.
