# First Cargo project created and run

The learner created `practice/day-02-cargo-greeting` with Cargo, then changed `src/main.rs` to print a personal greeting. They ran `cargo run` successfully from Zed’s integrated terminal and saw:

```text
Hello from Siseng's Cargo project!
```

They also inspected the new project structure: `Cargo.toml`, `Cargo.lock`, `src/main.rs`, and Cargo’s generated `target/` build-output folder.
