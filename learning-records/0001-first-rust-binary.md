# First Rust binary compiled and run

The learner created `hello.rs` in Zed, saved it, compiled it with `rustc hello.rs`, and ran `./hello` successfully. They also encountered and resolved the important edit-buffer versus saved-file mistake: `rustc` compiles what is on disk, not unsaved editor text. This is the foundation for the Day 2 Cargo workflow.

## Evidence

Terminal output: `Hello, Rust!` after saving and recompiling the file.
